Operation Dragon

YouTube  This tool uses YouTube API Services.

Operation Dragon is a private command-line tool used by a single independent creator to upload original short videos (animations rendered by code, with synthesized sound) to the YouTube channels they own, and to schedule their publication date.

It is not a public service: nobody else can sign in or use it.
