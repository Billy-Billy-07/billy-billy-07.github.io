Privacy Policy – Operation Dragon

Last updated: November 2026

YouTube API Services

Operation Dragon uses YouTube API Services. By using it, you agree to be bound by the YouTube Terms of Service. Google's handling of your data is described in the Google Privacy Policy.

What this tool is

Operation Dragon is a private command-line tool, run on its owner's own computer, that uploads original videos to YouTube channels owned by that same person.

Data accessed

The tool asks access to the owner's own YouTube account only, through Google sign-in (OAuth 2.0), with the scopes youtube.upload and youtube.readonly. It uploads videos with their title, description, tags and scheduled publication date, and reads the name and statistics of the authenticated channel. It does not access any other user's data.

Data stored

The OAuth access tokens and the IDs of the uploaded videos are stored locally, on the owner's computer only. No data is collected, and nothing is sent to any server other than Google's.

Data sharing

No data is sold, shared or disclosed to third parties. No cookies or trackers are used.

Data deletion and revoking access

Access can be revoked at any time from the Google security settings page. Deleting the local token files removes all stored credentials immediately. Stored data is never kept more than 30 days after access is revoked.

Contact

Questions about this policy can be sent through the contact details given in the Google Cloud project of this application.
