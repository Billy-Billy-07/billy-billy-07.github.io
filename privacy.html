Privacy Policy – Operation Dragon

Last updated: November 2026

What this tool is

Operation Dragon is a private command-line tool, run on its owner's own computer, that uploads original videos to YouTube channels owned by that same person, using the YouTube Data API.

Data accessed

The tool requests access to the owner's own YouTube account only (scopes: youtube.upload and youtube.readonly). It uploads videos and reads the name of the authenticated channel. It does not access any other user's data.

Data stored

OAuth tokens and the IDs of uploaded videos are stored locally on the owner's computer. No data is sent to any server other than Google's.

Data sharing

No data is sold, shared or disclosed to third parties.

Revoking access

Access can be revoked at any time from Google account permissions.

This tool uses YouTube API Services. See the YouTube Terms of Service and the Google Privacy Policy.
